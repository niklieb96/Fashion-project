# Fashion Archive

A curated fashion showcase — browse and manage a personal collection of fashion links.

## Deploy on Vercel

1. Import this repo at [vercel.com/new](https://vercel.com/new)
2. Click **Deploy**
3. After deploy: go to **Storage** tab → **Create Database** → **Neon Postgres** → **Connect**
4. **Redeploy** the project (Deployments tab → three dots → Redeploy)
5. Visit your site — go to `/admin` to add items

## Features

- Responsive grid with category filters and keyword search
- Editorial minimal design
- Admin panel at `/admin` — add, edit, delete items
- Neon Postgres database (auto-created on first request)

## Tech stack

Next.js 14 · TypeScript · Tailwind CSS v4 · Neon Postgres · lucide-react
